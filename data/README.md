# Dataset

The notebook downloads `Modified_SQL_Dataset.csv` here automatically:

1. from Kaggle via `kagglehub` (needs Kaggle credentials): <https://www.kaggle.com/datasets/sajid576/sql-injection-dataset>
2. otherwise from a public GitHub mirror of the same file.

You can also download it by hand and put it in this folder. Expected file: 30,919 rows, columns `Query,Label` (0 = benign, 1 = SQLi).
